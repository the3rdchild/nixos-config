## Sudah selesai

2. **Repo dipindah** dari `/mnt/doc/config` (lewat backup di `sda2`) ke `/mnt/shared/nixos-config`. Salinan di folder backup sekarang sudah basi, jangan diedit.
3. **Config dibersihkan dari SSD Team.** Sudah di-`switch`, generasi aktif `lbhpkd7h…-nixos-system-noouoops`:
   - `modules/filesystems.nix`: blok `fileSystems."/mnt/doc"` dihapus.
   - `modules/setting.nix`: `/etc/nixos` sekarang → `/mnt/shared/nixos-config`.
   - `home/shell.nix`: alias `nrs`/`nrst` → `/mnt/shared/nixos-config#noouoops`, abbr `sonora` dihapus.
   - `modules/openplc.nix` dihapus beserta import-nya (user sekarang pakai Omron).
   - Komentar di `power.nix`, `mime.nix`, dan `vm-network.nix` diperbarui. `docs/*.md` sengaja tidak diubah karena isinya historis.
4. **Diagnosa Windows selesai (read-only).** Kesimpulannya: Windows kemungkinan besar sehat.
   - BCD benar, SrtTrail "root causes = 0", chkdsk C: bersih, tidak ada crash dump, hibernate dan Fast Startup mati.

## Belum selesai
- [ ] **Commit perubahan config.** Belum di-commit, user belum memutuskan. Pesan commit harus diakhiri attribution line yang berlaku. File handoff ini jangan ikut di-commit kecuali user minta.
- [ ] **Windows (dikerjakan user di Windows):**
  1. Di layar Automatic Repair: Advanced options → **Continue**. Kalau gagal, coba Safe Mode (Startup Settings → 4).
  2. Kalau tetap gagal: ganti `BootExecute` jadi `autocheck autochk *` di hive offline, lewat `reg load` di WinRE atau hivex dari Linux. Yang lewat Linux berarti menulis ke NTFS Windows, jadi wajib minta izin.
  3. Setelah masuk Windows (cmd admin): `chkntfs /d`, `mountvol /r`. Lalu di Virtual memory, hapus D: dan set C: "System managed" (atau biarkan di E: saja). Program yang dulu ada di D: diinstall ulang.
- [ ] **Bersih-bersih:** `sudo umount /mnt/win; and sudo rm /tmp/BCD` (kalau belum).
- [ ] **Catatan (opsional):** folder `.claude/` (berisi `CLAUDE.md` → `@RTK.md`) dulu ada di folder induk repo lama, `backup-team/team/.claude/`, dan **tidak ikut tersalin**. Salin kalau masih dipakai.

## Catatan risiko
Repo sekarang ada di NTFS (`/mnt/shared`, `nofail`). Kalau Windows mati tidak bersih, ntfs3 menolak mount dan repo ikut tidak bisa diakses. Cara pulihnya: `sudo ntfsfix -d /dev/disk/by-uuid/57FE45F00AC89C8B`, atau chkdsk dari Windows.
